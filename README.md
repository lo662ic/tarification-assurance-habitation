# tarification-assurance-habitation
Projet académique Master Statistique et Economie du Risque (ex-ISEFAR) parcours Data Science et Actuariat. Modélisation d’un portefeuille d’assurance habitation en Python : tarification (OLS, IV/2SLS, GLM Gamma), modèles censurés (Tobit, Double-Hurdle), comptage (Poisson, Binomiale Négative) et analyse de survie (Kaplan-Meier, Cox).
